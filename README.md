# Job Market Telegram Bot

A Telegram bot that lets users set job search preferences (city, job title, keywords, job type) via inline buttons, then automatically matches and notifies them of relevant job listings sourced from official job APIs (Bundesagentur für Arbeit, Adzuna, Arbeitnow, Remotive).
